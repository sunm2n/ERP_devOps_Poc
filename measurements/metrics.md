# 지표 기록표

`plan.md` 5장. 값은 측정한 자리에서 채운다. 미측정은 `미측정` 과 이유를 적는다.

기록자·일시는 각 행의 `근거` 에 함께 남긴다 (예: `2026-09-03 김OO / journalctl 명령 출력 raw/h3-count.txt`).

## 계측 검증 — 이게 통과해야 아래 H3 값이 의미를 갖는다

| 지표 | 측정 방법 | 측정 시점 | 목표치 | 값 | 근거 |
| --- | --- | --- | --- | --- | --- |
| **계측 양성 대조 (IPv4)** | 제외 대역 밖 공인 IP 로 의도적 연결 1회 | 0단계 + `clean` 복구마다 | iptables 로그·pcap **양쪽에** 잡혀야 함 | | |
| **계측 양성 대조 (IPv6)** | 위와 동일 | 0단계 + `clean` 복구마다 | `ip6tables` 로그에 잡혀야 함 | | |
| 계측 생존 확인 | `iptables -L DOCKER-USER -n -v` / `systemctl is-active dnsmasq` | 복구 직후마다 | 규칙 잔존 + 싱크홀 가동 | | |
| OS 노이즈 baseline | 번들 미설치 상태, 동일 시간 캡처 | 0단계 | 초과분 계산의 기준선 | | |

> 양성 대조 없이 나온 "0건"은 증거가 아니라 정황이다. 계측이 꺼져 있어도 결과는 똑같이 0 이다.

## H3 — 폐쇄망

| 지표 | 측정 방법 | 측정 시점 | 목표치 | 값 | 근거 |
| --- | --- | --- | --- | --- | --- |
| **외부 통신 시도 (IPv4)** | baseline 초과분. 목적지 (IP,포트) 유일 조합 + DNS 질의 유일 이름 | **계수 창 A** (7번 ①~③) | **0** | | |
| **외부 통신 시도 (IPv6)** | `ip6tables` 로그 단독 근거 (libpcap `tcp[]` 오프셋은 IPv6 미매칭) | 계수 창 A | **0** | | |
| 재실행 안전성 (멱등) | **스냅샷 복구 없이** 연속 2회 적용 | 7번 ⑥ (별도 계수 창) | 멱등 | | |
| **서명 검증 실패 시 중단 (a)** | 이미지 tar 페이로드 1바이트 변조 | 7번 ⑧ (별도 계수 창) | exit≠0 + 서비스 미기동 + 로그에 `서명 불일치` | | |
| **서명 검증 실패 시 중단 (b)** | 다른 키쌍으로 전체 재서명 | 7번 ⑧ | 위와 동일 | | |
| 절차 우회 시 설치 성공 (c) | 검증 호출 제거 번들을 `verify-bundle.sh` 없이 실행 | 7번 ⑧ | **성공이 기대 결과** — 통제 수단이 절차임을 기록 | | |

판정 명령:

```
journalctl -k --since "<계수 창 A 시작시각>" | grep EGRESS-TRY \
  | sed -E 's/.*(DST=[^ ]+).*(DPT=[^ ]+).*/\1 \2/' | sort -u | wc -l

tcpdump -r raw/<창>.pcap 'tcp[tcpflags] & tcp-syn != 0 and not dst net 10.0.0.0/8 \
  and not dst net 172.16.0.0/12 and not dst net 192.168.0.0/16 and not dst host 127.0.0.1'
```

> 시도가 1건이라도 있으면 무엇인지 규명한다. NuGet, 이미지 pull, 라이선스 확인,
> 시간 동기화, **OCSP/CRL** 이 흔하다. 그 규명이 PoC 의 가장 값어치 있는 산출물일 수 있다.

> "역시 롤백 불가"로 읽게 된다. H5 는 실패 예상 가설이라 아무도 의심하지 않는다.
