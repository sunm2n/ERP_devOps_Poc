# 측정 기록

`plan.md` 5장 지표 19종을 기록하는 자리. **측정한 그 자리에서 채운다.**

## 규칙

**나중에 몰아서 하지 않는다.** 4단계(측정·정리)에 2~3일밖에 없고, 그때 되돌아가
재현하려면 VM-2 스냅샷 복구부터 다시 해야 한다. 검증 한 건이 끝나면 그 자리에서 적는다.

**추측을 값으로 쓰지 않는다.** 재지 못한 항목은 `미측정` 과 이유를 적는다.
빈칸으로 두면 4단계에서 "잰 것 같은데 기억이 안 난다"가 된다.

**근거를 남긴다.** 각 값에는 그것을 뽑은 명령이나 파일을 적는다. 다른 사람이
같은 명령으로 같은 값을 얻지 못하면 그 값은 보고서에 못 쓴다.

**합산하지 않는다.** 사람 개입 시간 / 운반 시간 / PoC 계측 오버헤드는 서로 다른 칸이다.
합치면 "폐쇄망 10분"은 무조건 실패하고, 빼면 근거가 사라진다. 환경 구축도
(a) 사내 1회성과 (b) 고객사 1곳당이 다른 칸이다 — 합산값을 고객사 수에 곱하면
100곳 추정에서 100배 과대계상된다.

## 파일

| 파일 | 내용 |

이 저장소는 PUBLIC 이다. 요약 수치만 `metrics.md` 로 옮긴다.

VM-2 는 폐쇄망이므로 `raw/` 로 옮기는 것 자체가 물리 복사다. **스냅샷 복구 전에
반출한다** — 복구는 증거도 지운다.
